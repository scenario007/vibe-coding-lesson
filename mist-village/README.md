# 雾谷来信（后端开发中）

这是独立的本地文字冒险项目。当前以 Scala 3 / Cats Effect / http4s / PostgreSQL 实现后端，前端原型暂不继续开发，也尚未连接后端。

## 启动后端

需要本机 Java、sbt 和 PostgreSQL 命令行工具。在 `backend` 目录运行：

```sh
python3 scripts/dev.py check
python3 scripts/dev.py serve
```

启动脚本在 `mist-village/.local/` 创建独立本地数据库，监听 `127.0.0.1:54349`；后端默认监听 `127.0.0.1:8089`。它不会自动启动前端。按 Ctrl+C 停止后端；数据库的数据保留在 `.local/`。

AI 使用课程文件中的 TokenHub `deepseek-v4.1-flash`，凭据只从本地 JSON 的 `api_key` 字段读取。脚本会尝试使用已有课程项目的共享账本和 `littlehero` 用户；共享账本不可用、账户不唯一、素材用量记录缺失或预算不满足时，模型请求会失败并保留世界状态。其他账户可通过环境变量 `MIST_LEDGER_USER` 指定。默认共享预算沿用此前的 10 元上限；这是预算估算，不等于平台余额或实际扣费。玩家自定义背景、秘密及主动提交的输入可能发送到 TokenHub，请只输入愿意发送给服务的内容。

接口字段、测试和配置见 [后端接口与验证说明](docs/backend-api.md)。

## 开发状态

目前已有两套预设事故基础线索、有限行动与结局、时间推进、人物状态、任务、骰子、有限物品和交易、成长、固定营地、存档、受约束的 AI 请求与共享预算记录。挑战模式由 AI 从有限事故要素中选择组合；它不是无限制生成的新物理规则。

这仍是**开发中的后端原型**：剧情和人物互动尚不足以支撑约定的 3～5 小时中篇；NPC 信息传播目前只覆盖少量预设关系；战斗、个人秘密支线、AI 自选方案和剧情内容仍是有限原型。不要把现有前端或这一后端当成正式完成的游戏。
