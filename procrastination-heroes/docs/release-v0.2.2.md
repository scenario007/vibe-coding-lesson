# v0.2.2：明确提示阿里云图片认证失败

当阿里云图片接口返回 HTTP 401 时，奖励草案会保留文字计划并展示认证失败提示，不再只显示含糊的“图片暂时不可用”。定制家具遇到同一错误时会返回明确提示，交易回滚且不扣冒险币。

本机检查确认后端已读取当前本地 Key；阿里云返回 `InvalidApiKey`。只读的地域认证检查也未成功，不能仅凭这些结果断定是密钥失效、复制错误、套餐类型还是地域不匹配。未发起新的图片生成请求。配置工具现会拒绝明显的脱敏 Key，并提示选择北京地域的普通模型 API Key。

验证使用本地模拟接口和隔离数据库，覆盖 401 提示、文字计划保留、家具不扣币及不自动重试；没有产生阿里云模型调用费用。
