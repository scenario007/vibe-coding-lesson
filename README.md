# Vibe Coding 课程项目

当前项目：[拖延勇者协会](procrastination-heroes/README.md)，当前版本 v0.2.0，首版标签 v0.1.0。

GitHub 仓库：[scenario007/vibe-coding-lesson](https://github.com/scenario007/vibe-coding-lesson)。

让 AI 将目标拆成可执行的阶段、设计任务专属纪念物，用每次进展积累成长并装饰自己的小屋。包含 10 类页面及真实的 Scala / PostgreSQL 后端。

- [启动、配置与演示说明](procrastination-heroes/README.md)
- [架构与课程规范映射](procrastination-heroes/docs/architecture.md)
- [构建、集成与浏览器验证记录](procrastination-heroes/docs/verification.md)
- [课程材料阅读记录](docs/course/README.md)

技术栈：React、TypeScript、Tailwind、Vite；Scala 3、Cats Effect、http4s、Circe、PostgreSQL。

本机双击 `procrastination-heroes/Start.command` 启动，使用 `Stop.command` 停止。换电脑时请按项目说明准备依赖，并配置自己的后端凭证文件。仓库不包含模型密钥、开发数据库、依赖目录或构建缓存。

每个完成版本在验证后提交并推送到指定远程仓库，提交说明概括该版本的变化与验证情况。
