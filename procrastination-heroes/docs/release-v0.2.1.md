# v0.2.1：接入阿里云专属素材生成

日期：2026-10-28。

这版把奖励和补给铺家具的图片生成接入后端阿里云百炼 `wan2.7-image`。每次新建或重新设计奖励、定制家具时，后端使用统一的“公会手账＋废柴勇者”提示词，要求 1:1、1K、单主体、无文字和无水印，并把百炼返回的临时图片下载到本地素材目录后再返回前端。

图片 Key 只从 `ALIYUN_DASHSCOPE_API_KEY` 或 `DASHSCOPE_API_KEY` 读取，不能进入前端或 Git。没有配置 Key、图片开关关闭或接口失败时，任务和家具仍保留原有 SVG 兜底；启用 `ALIYUN_IMAGE_GENERATION_REQUIRED=true` 才会把图片服务失败升级为操作错误。

奖励设计和商店家具新增可选 `imageUrl` 持久化字段，旧数据通过数据库启动迁移自动补齐。奖品展板、据点素材库、自由画布、成长档案和任务详情会优先显示 AI 图片，缺失时显示公会手绘部件。

本版不在仓库保存 API Key，也没有发起真实图片请求；需要使用时，将新生成的 Key 写入本机 `.env.local` 后重启服务。模拟接口检查了模型、画幅、提示词和图片下载；隔离数据库的模拟流程验证了 AI 奖励预览、保存、家具生成及固定模式跳过生图。原有业务集成检查通过 25 项，前端类型、构建、格式及后端编译通过。图片生成失败后保存草稿不会自动重试，用户可以主动再次设计。
