# 架构与实现范围

## 课程规范

本项目采用课程要求的 React/TypeScript/Tailwind 与 Scala 3/Cats Effect/http4s/Circe/PostgreSQL。用户提供的 60 条 rules 是实施依据，快照见 [course-rules.txt](course-rules.txt)，完整课程阅读记录在工作区上级 docs/course。

- 业务模块与系统基础设施都在 services 下；每个服务使用 api、objects、routes、tables、utils。
- API 是独立消息文件，构造字段承载输入，只有响应泛型，执行入口 plan(connection): IO[Response]。
- 前端按服务提供对应 API 类及 send；统一从类名推导路由。Vite 生产构建显式保留名称，避免压缩破坏接口名。
- 路由先验证外部令牌、替换可信 userId，业务代码不信任前端自报身份。
- 一个领域对象一个文件；传输响应放 objects/apiTypes；有限任务、计时、生成、头像、图案、配色和房间位置采用封闭类型。
- 每表自己的文件夹含 Table 与 Initializer；Sql 私有并紧邻对应公开 def。行映射私有，公开方法返回 IO[T]。
- 业务 API 可以调用任意服务公开 Table 方法和消息 plan；服务 utils 对所属服务私有。
- 复杂页面入口保留主要业务区域骨架；页面专用 hooks 与区域组件就近组织。共享 components 仅放通用 UI。

系统共享连接/事务在 system/api/DatabaseSession，提供基础设施公共边界；JDBC 资源执行器在 system/tables/Jdbc，只有各 Table 使用，业务 API 不传入 SQL。system/utils 的 Main 是框架要求的公共启动入口，其他工具维持系统范围可见。没有新增转发 Service 层。

## 数据与事务

共 16 张表，初始化 SQL 归各模块。本实现直接从奖励账本计算今日累计，在钱包行锁下保证上限，不额外维护易失去同步的 daily_reward_totals 表。

任务完成按钱包→任务的稳定顺序锁定，检查归属、状态和前置步骤，原子写步骤、奖励事件、钱包、经验及最终纪念物。step_id 唯一防止重复结算，quest_id 唯一防止重复解锁。

商店购买锁钱包，验证余额及已购记录，原子扣款与发物；同一商品不能重复购买。统一 room_placements 表保证每个槽位只有一件装饰，API 验证物品持有与位置适配。

专注会话持久保存服务端时间，暂停记录一个已结束区间，继续开启新起点。唯一活动会话索引阻止并发多开；统计将区间按上海自然日切分。前端不能自报已专注秒数。

## AI

用户提交生成请求后立即返回后台任务，数据库连接释放。单个后台 worker 取任务后调用 TokenHub，再用短事务保存经类型与语义校验的结果。网络调用不占用数据库事务。GenerationRuntime 是公开的后台资源生命周期边界，启动时不传递空连接或长时间持有数据库连接。

模型输出有 1–5 个阶段、动作清单、估计分钟、完成标准、前置阶段与专属奖励。用户名、账号历史与密钥不进入提示词。响应验证失败不写正式任务，不使用假数据伪装成功。工作台可以查询并找回本人最近成功的草案。

用户可编辑或重新生成，确认之后保存草稿或开始冒险。开始后锁定奖励预算与阶段结构，仍可修改日期和复盘。首版没有进行中任务的有奖阶段重构界面；可以在已有步骤说明基础上自行推进，复杂 AI 重排作为后续扩展。

每账户每天最多提交 20 次生成请求；输出上限 1800 token；模型超时 75 秒。后台失败保留可解释的错误，不打印凭证与原始服务端敏感响应。

## 界面和边界

10 种页面模板中，登录/注册与任务创建/查看/编辑分别复用模板。地图是固定区域和等级解锁；据点是 6 个固定位置；奖励为 AI 内容加受控模板，而不是图像模型独立绘制的家具。没有支付、公开排行榜、好友社交或管理员管理站点。

活动任务与普通查询目前使用单账户最多 500 项任务、最近 2000 条奖励与 100 条专注会话的展示上限，适用于本地课程首版；大规模部署应增加正式分页、迁移、日志与生产认证配置。

注册账户默认空存档，后台不会自动补全现实任务或伪造经验。集成测试账户的数据确由接口创建和完成，仅用于本地验证。

## v0.2 美术与费用账本

保持原 10 类页面及业务流程，用公会手账、独立装备/家具轮廓、角色姿态和少量轻动画替换森林式通用界面。新增矢量素材为 UI 资产，静态角色按任务/计时状态切换；减少动态效果遵从系统偏好。奖励类型扩为 12 种，使用 Scala enum / TS union，校验依赖有限类型，不再维护会漏更新的字符串白名单。

新增 `ai_usage_events` 表和一个本人明细/项目汇总 API。网络调用前以 PostgreSQL 事务级 advisory lock 原子校验共享预算并预留；网络调用在事务外执行，返回 usage 后短事务结算。请求未确认或服务重启保留预留；重复结算不覆盖已记录结果。按当前广州 DeepSeek Flash 峰谷、缓存费率计算估算，不重复计推理 Token。

离线素材工具使用相同预算锁，读取文本账本并原子更新素材 manifest；实际图片请求在锁外。查询接口合并固定素材历史与本机文本记录，本人只能读本人调用明细，汇总不暴露他人输入或密钥。普通推理 Key 不具备 TC3 余额查询权限，API 明确 `billingConnected=false`。用户本轮不启用付费图片，图像调用开关默认关闭。
