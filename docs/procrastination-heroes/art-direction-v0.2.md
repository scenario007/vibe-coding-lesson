# v0.2 美术素材执行单：废柴勇者公会

日期：2026-10-25。本子任务只准备素材规范与提示词，**没有调用图像或文字模型，没有产生 TokenHub 费用**。主代理已确认选用 seedream-image-v5.0-flash；实际价格来源、调用与账单核对归主实现流程。

## 视觉基准

现有截图中，森林背景、细线图标与浅绿圆角卡片占据主体，角色和藏品缺少轮廓辨识。新版本采用公会手账与独立漫画的共同语言：炭黑粗线、略抖的手绘轮廓、平涂色块、小面积排线、羊皮纸、暗红印章、贴纸与胶带。情绪是困倦、笨拙但愿意行动，带大学生式的干涩幽默。

- 底纸 #F2E5C7，墨线 #30281F，披风与印章 #A64534，史莱姆与布料 #73805A，金属暖光 #D4A33E。
- 角色采用大头小身体和半睁眼，120–240 CSS 像素仍能看清表情、锅盖和披风。
- 线宽一致，外轮廓比内部线条粗，少量排线；避开柔焦、写实油画、3D 光泽和森林风景。
- 所有中文、任务内容、按钮、印章文字、数字、倒计时均由 React 显示，图像里不烘焙文字。
- 公告板、纸条、图钉、印章外形由网页绘制；奖励由独立 SVG 插画部件承载，本轮不额外购买奖励图集。

参数：background=transparent。

> 制作透明背景角色图集，2048×2048，严格2列3行六个等大格，每格四周留足透明间隔，无格线。六格是同一成年中性小勇者：豆形圆脸、半睁黑眼、一撮乱卷发、皱暗红披风、灰橄榄短衫、棕短靴、凹锅盖盾牌和折纸稿剑。按行依次：站立发呆、挠头犹豫、提剑开工、举盾庆祝、趴地休息、抱卷轴认真读。各姿态完整不越格，比例一致。炭黑粗细统一的微抖手绘墨线、少量排线、哑光平涂，暖羊皮色与暗红橄榄配色，笨拙困倦但可爱。无字、无数字、无标签、无界面、无水印、无阴影底板，无3D和渐变。

验收重点：同一发卷、披风、锅盖和身体比例；6 种姿态从外轮廓可分辨；每格独立且有足够透明间隔。模型不保证精确等格，必须目视检查。

## 实现与费用边界

1. 逐张生成并记录模型、尺寸、请求、用量、估算/实扣和结果；成功图片不自动重试，未知价格时不试模。
2. 若接口支持参考图，后两张沿用首张作为风格参考；否则完整保持相同墨线、配色与平涂要求。
3. 原始 PNG 保留以核对 alpha 和图集间隔；网页格式转换不覆盖原图，也不能掩盖图片本身的布局问题。
4. 新图未落地前不声称已经生成或扣费；SVG 奖励与模型生成图片仍须如实区分。
5. 本文件只准备设计，不调用 API，不改应用源码。主代理负责生成、保存、集成、浏览器验证和 Git 提交推送。
