# v0.2.3：先整理需求，再生成素材

奖励和家具生图前调用 TokenHub 小型文字模型整理视觉描述，原始需求和整理结果同时发送给 `wan2.7-image`。用户指定的材质、颜色与形状优先；公会风格不再强制为素材加木头、羊皮纸或印章。文字调用按原有预算锁预留并入账；图片调用仍在阿里云，费用不包含在 TokenHub 账本中。

家具先生成预览，显示整理后的描述并允许比较抠图版与原图。领取时才扣 5 冒险币，并通过数据库锁防止重复领取。模型费用在生成预览时产生或抵扣，不因取消领取而撤销。

本机尝试去除与图片边缘相连的近白色背景，保留原始文件；未检测到适合处理的背景时显示原图。该方法不是智能分割，白色或透明主体、细边和封闭空隙可能处理不准确，预览中可选择保留原图。现有素材不被自动替换。

以本地模拟服务和隔离数据库验证了文字整理、生图、预算事件、预览、重复领取、用户隔离和失败不扣币；本机测试了纯白背景处理及不符合条件时保留原图。没有发起真实图片生成，因此实际材质表现仍需用户按需验证。
