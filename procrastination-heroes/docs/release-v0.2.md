# v0.2.0：废柴勇者公会与费用账本

日期：2026-10-25。

## 这版改变了什么

保留原有 10 类页面、用户存档及完整任务流程，将通用森林风格替换为公会手账：羊皮纸、炭黑墨线、暗红印章、歪斜的纸质委托、木公告板与独立战利品轮廓。

- 锅盖勇者六种姿态：站立、犹豫、开工、庆祝、休息、读卷轴。
- 史莱姆四种姿态随专注状态切换，支持轻微呼吸动画及系统减少动态效果设置。
- 原创矢量小屋、12 种任务奖励部件、12 件真正有独立家具形状的商店物品。
- 新增稿纸剑、锅盖盾和冒险卷轴，与旧的九种图案兼容；类型、编辑器、AI 提示词、校验与持久化全部同步。
- 费用账本每 5 秒读取本地后台，显示本项目已观测 Token、按公开费率估算、待核对预留及剩余预算；本人明细只对本人开放。

素材是原创 SVG，文案与奖励参数可由文本 AI 设计。没有把部件组合描述为“每份奖励独立 AI 生图”。静态素材的源码分别在 `frontend/src/components/ui/AtlasSprite.tsx`、`RewardIllustration.tsx`、`FurnitureIllustration.tsx` 和 `pages/Base/components/RoomScene.tsx`。

## 图像付费决定与实际费用记录

用户先授权本轮新增 TokenHub 费用上限 10 元，随后明确选择“本轮暂不启用图像付费”。因此，本版使用原创矢量插画完成美术，没有再请求收费图片，也没有转用其他收费图像服务。

在收到停止图片付费的选择之前，做了两次 Seedream Flash 请求：第一次失败记录只有 HTTPError；为补全错误诊断做的一次人工重试返回 402 / 401007，明确说明没有免费额度且后付费未启用。两次均未返回图像或 usage，素材 manifest 保留合计 **0.24 元待核对预留**。它不是“已扣费 0.24 元”，也没有被静默记成 0。

文本真实联调两次合计返回 **1,757 Token**，按已核实费率估算 **0.00452 元**。其中第一次因新增奖励仍被旧白名单拒绝而未形成计划，返回用量仍如实记账；修正为使用有限类型校验后，第二次完整任务链路通过。没有隐去失败请求的用量。

交付时本项目已观测用量对应估算 0.00452 元，待核对预留 0.24 元，剩余调用预算 9.75548 元。具体值会随用户后续调用更新。现金余额和最终实扣未连接，最终以腾讯云账单为准；旧版本在账本启用前的调用不在本轮记录中。

## 费用保护

- 请求前使用 PostgreSQL 事务锁原子检查全项目预算，再持久化保守预留，网络请求在事务外执行。
- 未命中输入与最大输出按高峰费率预留；返回后按真实 usage、缓存及峰谷时段更新估算，不重复累计 reasoning Token。
- 请求前后任一时间落在官方周一至周五高峰时段时采用高档保守估算。本地时间不是平台实际接收时间，因此不会把估算称作平台实扣。
- 超时、无 usage 或重启中断保留预留；重复结算不会覆盖已记录值；未配置费率的模型在请求前被拒绝。
- 素材操作工具与在线文本请求共用同一个预算锁。图像调用默认关闭，用户本轮关闭选择优先于此前的生图计划。
- 重启不重置预算，也不自动重试收费调用或开通后付费。

## 复核命令

先启动应用，再运行：

```bash
python3 scripts/usage_meter_test.py
python3 scripts/usage_api_test.py
python3 scripts/integration_test.py
node scripts/check_api_names.mjs
```

`integration_test.py --ai` 会新增一次真实文本调用，本次成功联调后未为重复验证再调用模型。图像工具默认 dry run；实际生成另需明确授权、图片开关、当日价格核实与预算锁。
